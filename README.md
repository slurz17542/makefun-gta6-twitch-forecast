Forecasts GTA VI's launch-day Twitch viewers hour by hour: for each of hours 2–24 it writes five quantiles of the concurrent-viewer count, learned from the launch-day curves of 37 past big game launches (a per-hour regression of the log viewer ratio on log hour-1 size, blended with the empirical median and a residual-based spread).

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
